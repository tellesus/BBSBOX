# BBSBOX

BBSBOX is an offline neighborhood community platform: independently operated local BBSes, modern customizable interfaces, chosen mesh connections, physical Pigeon message carriage, and games.

This repository currently contains design documentation, not an implemented product.

- [Tier 1 master specification — v0.4.0](BBSBOX_MASTER_SPEC.md): settled scope, proposals, boundaries and change history.
- [Technical proposal — v0.1.0](BBSBOX_TECHNICAL_PROPOSAL.md): recommended architecture and modular delivery strategy; choices remain proposed.
- [Development index](docs/development/README.md): choose one module and its short reading packet.
- [Start a bounded task](docs/development/START_HERE.md): work and handoff conventions.
- [Decision register](docs/development/DECISIONS.md), [scope coverage](docs/development/COVERAGE.md), and [work ledger](docs/development/WORK_LEDGER.md).
