## Acceptance record template

`ADR ID/version; affected T row; status; owner/date; problem; recommendation; alternatives; prototype evidence; chosen scope; consequences; contracts/modules changed; migration/rollback; unresolved limits; supersedes.`

Keep one ADR per material decision under `docs/decisions/` when a decision is actually taken. Do not create a ceremonial Accepted ADR merely to mirror this proposal. A module can prototype alternatives while its decision remains Proposed.

## Primary technical references checked for this proposal

- [Axum](https://docs.rs/axum/latest/axum/) describes the HTTP framework and Tokio integration.
- [SvelteKit static adapter](https://svelte.dev/docs/kit/adapter-static) supports a locally served static build; our authenticated app routing still needs its prototype.
- [SQLite WAL](https://www.sqlite.org/wal.html), [backup API](https://www.sqlite.org/backup.html), and [rusqlite](https://docs.rs/rusqlite/latest/rusqlite/) inform concurrency and snapshot design. WAL has one writer and requires local shared-memory access; it is not a network database replication mechanism.
- [RFC 8949](https://www.rfc-editor.org/rfc/rfc8949.html) and [RFC 9052](https://www.rfc-editor.org/rfc/rfc9052.html) define CBOR/COSE; our application profile and vectors still need specification.
- [RFC 9420](https://www.rfc-editor.org/rfc/rfc9420.html) and [OpenMLS](https://book.openmls.tech/) establish the MLS candidate. OpenMLS lists mobile/WASM targets as built but not tested on upstream CI; library availability is not proof of our supported-device behavior.
- [Browser secure contexts](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts) and [Tauri distribution](https://v2.tauri.app/distribute/) inform client feasibility. Neither guarantees frictionless offline installation on every phone.

References were inspected on 2026-10-25. No dependency version is pinned by this design document. License and router-specific implementation documents need verification during their decision work; the corresponding candidates are not claimed as validated deployment choices.
