## Recommended implementation

Start with two nodes/one courier, then exercise the proposed three-node/two-courier fixture. Add one measured offline IP mesh configuration, with OpenWrt/802.11s as a hardware-dependent candidate rather than an assumed universal router capability. Observe a gathering, disconnected exchange and continuity exercise. Use local consented observation notes and operational timings; no cloud analytics or screen-time optimization.
